# How Ren 2 memory works

Markdown notes in this folder are the human-editable copy of Ren 2's memory. Put a note
under a project folder (e.g. `storefront/`) and optionally start it with front matter
(`project:` and `kind:` — fact, decision, preference, playbook, lesson). Ren 2 indexes
changes within 30 seconds. Imported old-Ren notes land in `imported/`.
